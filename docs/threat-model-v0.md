# Threat Model v0 — Rat Next (P0)

**Дата:** 2026-10-01 · Статус: **v0** (черновик уровня P0; полный STRIDE-анализ — в
`docs/ARCHITECTURE_DESIGN_v1.1.md` §6)

## Область и границы доверия

- Компоненты: Viewer (оператор), Agent Service (Session 0), Session Helper, Relay,
  Signaling/Registry, Update server.
- Границы доверия:
  - Интернет/relay — **недоверенные**: relay видит только шифротекст + метаданные
    (ID, время, объём); содержимое — насквозь зашифровано (E2E);
  - Viewer — доверенный, но рассматривается и сценарий компрометации;
  - ОС управляемой машины — защищаемся от внешних угроз; локальный админ — вне модели.

## Ключевые угрозы и митигации (сводка)

| # | Угроза | Митигации |
|---|---|---|
| 1 | Malicious relay (MITM/spoofing) | E2E Noise_XX; SPAKE2 по PIN; пиннинг Ed25519-идентичностей |
| 2 | Компрометация viewer (EoP) | scopes прав, per-agent ACL, аудит, отзыв ключей/устройств |
| 3 | Replay | эфемерные ключи на сессию; nonce/ts-окна; привязка к device-ключам |
| 4 | DoS signaling/handshake | rate-limit (сессия/агент/глобально), капы соединений, блок-листы |
| 5 | Supply chain | фикс версий, cargo-deny/audit, SBOM, минимум зависимостей |
| 6 | Подмена канала обновлений | подписанные манифесты (offline root), staged rings, rollback |
| 7 | Локальный EoP на агенте | строгая валидация IPC (schema+границы), ACL pipe, path-validation |
| 8 | Энумерация 6-цифровых ID | ID — псевдоним; доступ решают ключи; уникальность ID; rate-limit на поиск |
| 9 | Clipboard-утечки | политика синхронизации; ограничение типов (текст/CF_HDROP) |
| 10 | Утечка ключей на диске | DPAPI (machine scope) / опция TPM |
| 11 | Злоупотребление auto-allow | авто-подключение только для ACL-операторов; пиннинг при первом коннекте; аудит |

## Дополнительно по итогам P0

- Зависимость от GPU-драйверов (найден краш Vulkan-пути в драйвере Intel `igvk64.dll`) —
  влияние на **доступность**, не на ИБ; зафиксировано требование к бэкенду (DX12) —
  см. `spikes/UI_KIT_DECISION.md`.
- Обновления и AV-совместимость — см. §2.7/§4.6 проектного документа; code signing
  отложен до появления юрлица (пилот — без подписи, в собственном контуре).

# REPORT — спайк ui_egui

**Дата:** 2026-10-01 · **Статус:** ✅ built + ran OK (smoke)

## Цель

Оценить egui/eframe 0.36 как UI-кит вьюера: макет «панель устройств + область видео
(заглушка) + строка статуса», smoke-запуск (авто-закрытие через ~4 c).

## Результат

```
UI_EGUI_STARTING smoke=true
UI_EGUI_SMOKE_OK
```

- Инкрементальная сборка: ~8 c (после первой полной сборки дерева).
- Окно открывается и закрывается штатно (smoke-режим).

## Найдено (важно для архитектуры)

- **eframe 0.36 по умолчанию использует wgpu, и на этой машине wgpu выбирает Vulkan →
  падение в драйвере Intel (`igvk64.dll`, ACCESS_VIOLATION, 0xc0000005).**
  - Проверено: `WGPU_BACKEND=dx12` и `WGPU_BACKEND=gl` — работают; Vulkan — падает.
  - В спайке по умолчанию выставляется `WGPU_BACKEND=dx12` (в коде, если не задано извне).
  - Для продукта: явно настроить бэкенды в `WgpuConfiguration` (DX12) и учесть в требованиях
    к драйверам целевых машин.
- API egui 0.36 существенно обновился: `App::ui(&mut Ui, &mut Frame)` вместо `update(ctx)`;
  панели — единый `Panel::left/bottom(...).show(ui, ...)` + `CentralPanel`
  (старые `SidePanel`/`TopBottomPanel` убраны).

## API-заметки для вьюера

- Видео-поверхность: MVP — кадр как текстура egui (просто, +2–4 мс); оптимизация — child-HWND
  с D3D11 flip-моделью.
- Док-панели (файловый менеджер/терминал) — через `egui_dock`/`egui_extras` (проверить в P1).

# REPORT — спайк ui_iced

**Дата:** 2026-10-01 · **Статус:** ✅ built + ran OK (smoke)

## Цель

Оценить iced 0.14 как альтернативный UI-кит вьюера: тот же макет
(панель устройств + область видео-заглушки + строка статуса), smoke-запуск.

## Результат (фактический вывод)

```
UI_ICED_STARTING smoke=true
UI_ICED_SMOKE_OK
```

- Инкрементальная сборка ~40 c; окно открывается/закрывается штатно.
- Smoke-запуск проверен **и без переменных окружения, и с `WGPU_BACKEND=dx12`** — работает в обоих
  случаях (в отличие от eframe/wgpu 30, который на Vulkan-пути падал в драйвере Intel).
- Дефолтные фичи iced 0.14: `wgpu` 27 + `tiny-skia` + `thread-pool` и др. (~382 крейта в графе).

## Нюансы API (для оценки стоимости)

- `horizontal_rule()` убран → `widget::rule::horizontal(1)`.
- Для `iced::time::every` и подписок нужна фича `tokio` (или `smol`) — без неё модуль времени пуст.
- Модель приложения: `iced::application(boot, update, view)` + `.subscription(...)`; сообщения/`Task`.

## Выводы

- iced пригоден и работает на целевой машине без обходов.
- Экосистема виджетов для инструментальных панелей (док-панели, таблицы) беднее, чем у egui —
  учтено в решении `../UI_KIT_DECISION.md`.
